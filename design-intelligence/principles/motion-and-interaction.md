# Motion & Interaction — consolidated principles

Sources: S03 (delight-only motion, character-true), S02 (feedback contract, confirmation
micro-interactions), S07 (feedback immediacy/counted CTAs), S01 (skewed product cards),
S12C (prototype dissolve enter/leave). Class key: **[G]** · **[R]** · **[C]**.

## Rules
- **One job per surface**: entrance, feedback, or delight — never stacked on the same element. [C→R]
- **Personality dial**: motion volume set by the pre-decided corporate↔playful position; delight
  only where the dial allows. [C: S03]
- **Character-true transitions**: motion direction/modal must match the content's meaning
  (inflow vs outflow). [C: S03]
- **Feedback immediacy**: every control answers within one beat — counted CTAs ("Show 41
  homes"), per-option counts, pressed states, badges; no 7-tap silent filters. [G]
- **Confirmation micro-interactions**: destructive/important actions get a dedicated acknowledge
  moment (not an alert swap). [R]
- **Loading is visible**: button-level loading state, not global freeze. [RP: S02]
- **Marketing product-motion**: skewed/flying real-product cards when legible; anchored to real
  UI, not abstract shapes. [C: S01]
- **Prototype transitions**: dissolve pairs for enter/leave in flow demos (course). [C: S12C]
- Reduced-motion fallback for all of the above. [`outside-source`]

## Failure modes (verified images)
- Filter takeover with zero feedback (S07 junior ladder, before state).
- Motion stacking on hero elements fighting legibility (S03 one-effect rule).
