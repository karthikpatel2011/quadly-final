# Pattern: Page structures — the column-count taxonomy (Self-Made Web Designer library)

Sources: video-17 (33 layouts, 28 frames), video-23 (17 examples, 27 frames). This is the
strongest LAYOUT-STRUCTURE source in the library. All variants cite research/video-17/23.md
with frame evidence.

## The core claim (verified)

A page is composed of 1–6 columns, where **a column is defined by alignment, not by visible
rectangles** ("looks like 3 but is 2" — grid overlay verified, S23). Above ~6 columns you're in
utility/edge cases ("hardly ever above a six column layout", S17).

## 1 column — one message, one action
- Centered hero (Finta), left-aligned (Paper Design), text-over-image (Family Style) — with
  RAAD as the contrast-failure case, funnel composition (Nick Tarasov), text-only display-type
  page (State of Create), pop-in media (Portrait).
- Use for: single-goal pages, launches, links-in-bio-grade focus.

## 2 columns — message + evidence
- Dual-tone headline (Gilion), cards version, image/text split ("necessary but don't lean on
  it as a crutch"), stacked-media + whitespace gap (TechTO), bento + flopped bento (Arch
  Agency), hairline+icon text stacks (Perplexity), 1-over-2 mix with type-caliper rules
  (Seed Design).
- The workhorse structure for product marketing.

## 3 columns — three co-equal ideas (compare / tiers / testimonials)
- Diagonal main-character composition (Square Banking), oversized-initial symmetric cards
  (We Are 38), rotated cards + mobile swipe-lane (GSAP), bento with ONE saturated focal tile
  (zeroG), flipped card anatomy (Localyzer), whitespace-asymmetric × anti-ghost-button
  (Enlighten), spotlight reassurance card ("No obligation", Ridecar), before/after icon
  polarity (Resync Bio), gaze-directed bookended images.

## 4 columns — catalogs/blogs/products
- Unfilled grids as a whitespace TOOL; numbered package cards (VW Lab 001–004); draggable
  decks (Gilion); two-focal-point event rows (TechTO); "design for the longest entry" (dynamic
  content rule); 4→2 mobile collapse only when images are decorative (Appcore).

## 5–6 columns — structure/utility only
- Image-service tiles need legibility scrims (SpaDerma); accordions must NOT have rotated
  labels; nested grids (Ramp 4×3=12); artistic asymmetry warning (Ariel Childs); editorial
  "birdshot" for multi-goal sites (Huffington Post); gridded footers.

## Cross-cutting theory (S23, verified with named anti-examples)
- Hierarchy via contrast/size/color/whitespace — anti-examples: Goodreads, Yale School of Art.
- Variation with purpose (change one variable at a time across a grid family).
- Balance without symmetry; the 60-30-10 proportion rule reappears here too.

## Where this fails
- Static "33 layouts" claims were never itemized on-screen — the taxonomy is the analyst's
  verified distillation (~17 distinct patterns frame-verified); motion behaviors (drag decks,
  parallax) remain unproven from stills (S17 gap log).
