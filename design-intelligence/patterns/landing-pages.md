# Pattern: SaaS landing pages

Evidence: video-01 L01-10/L01-8 (+frames t00m5m40/t00m5m55/t00m6m05/t00m4m33), video-03
(word-widgets, 404, motion), video-10 (type laws applied to marketing pages), video-06
(product-page trust adjacency).

## Anatomy that earned trust in the sources

1. **Hero = statement + one action + product-as-graphic** (01): short ≤2-line headline
   ("Shorten links. Expand your reach."), one-line sub, single input-or-CTA; graphics are the
   REAL product: skewed/flying link-row cards echoing the dashboard rows, motion-blurred.
2. **Feature sections use real app UI, not icon cards** (01 t00m6m05): split layout — live
   product form left, benefit headline + "Learn more →" right. Icon-card grids were explicitly
   called the thing that loses customers ("standard of quality… establishes trust even
   subconsciously", 5:42–5:46).
3. **Pricing**: 3–4 plans; plan name small/centered; PRICE huge; discount badges honest
   ("Early Adopter"); show what next tier adds ("Upgrade to Standard" + delta list); top tier
   "Enterprise · Custom" when limits exceed self-serve (01 t00m4m20; reference: Resend-style
   "Predictable pricing" with From-$ pricing, overage lines, "Everything in Pro, plus:"
   checklists — t00m4m33).
4. **Trust adjacency** (06): rating/score directly under title; proof near claim.
5. **Type laws applied** (10): hierarchy first (what wins: headline? social proof? CTA), 45–75
   char measure, left-aligned body, chunked sections with ≤6-word titles, serial positioning
   (context early, decision last).
6. **Personality budget** (03): decide the "playfulness dial" position before restyling; one
   motion effect per section; word-widgets (a real UI element embedded IN the headline) as the
   memorability device; themed 404 with the same dial.

## Anti-patterns named in the sources
- Template icon-card features ("lame-ass icons", 01 5:58), dead stat cards, 5+ plans,
  unlabeled discounts, rainbow accents (01/04/09).

## Responsive note
- 01/06 are desktop and mobile mockups respectively; mobile buys: sticky buy bar + sticky
  title (06). Detailed breakpoints not taught → treat as `outside-source` CSS media work.
